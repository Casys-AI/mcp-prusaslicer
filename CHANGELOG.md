## 0.3.0

- `prusaslicer_estimate_fff` returns `engine_name` and `engine_version` parsed from the
  G-code `; generated by` header.
- `effective_config_sha256` is the SHA-256 of the exact emitted `prusaslicer_config`
  block (`begin` through `end` markers), not of the input INI.
- `overrides_applied` lists only the caller-provided print overrides that were forwarded
  (`layer_height_mm`, `infill_percent`, `filament_density_g_cm3`).
- `timeout_ms` is validated as a positive integer in the JSON Schema, the tool handler,
  and the PrusaSlicer bridge.
- Unit tests call the production G-code parser (`parseGcodeStats`) instead of
  re-implementing the statistic regexes.

## 0.2.0

- `scripts/stdio-shim.ts`: stdio → stateless-HTTP adapter. Classic-SDK stdio clients
  (Docker MCP Toolkit, desktop hosts) get `initialize` answered locally from
  `server/discover`; everything else is forwarded in the 2026-07-28 stateless envelope,
  which is the only revision the server accepts on the wire.
- `docker-entrypoint.sh`: the image now has two run modes — `http` (default, unchanged)
  and `stdio` (`docker run -i <image> stdio`).

## [0.1.0] — 2026-08-05

### Added

- `prusaslicer_estimate_fff` — FDM slicing estimation via PrusaSlicer CLI. Caller
  supplies a `stl_path` (absolute path) and a `profile_ini_path` (absolute path to a
  PrusaSlicer INI); the tool returns print-time and material-consumption measurements
  from the real G-code comment block. No prices emitted (pricing is downstream,
  erpnext).

- Input overrides on top of the profile: `layer_height_mm` (`--layer-height`),
  `infill_percent` (`--fill-density N%`), `filament_density_g_cm3`
  (`--filament-density`). Each forwarded as an explicit CLI flag.

- Input attestation: `snapshotStlArtifact` and `snapshotIniArtifact` copy both inputs
  into private temp directories, compute SHA-256, optionally verify caller-supplied
  digests (`stl_sha256`, `profile_sha256`), and freeze the copies read-only (0o400)
  before any subprocess sees them. The attestations are returned as `stl_artifact` and
  `profile_artifact`.

- Output fields:
  - `print_time_s` — normal-mode estimate in integer seconds
  - `print_time_normal_mode` — raw G-code string (e.g. `"19m 50s"`)
  - `print_time_silent_mode` — raw G-code string or null
  - `filament_length_mm` — filament path length in mm
  - `filament_volume_mm3` — filament volume in mm³ (G-code cm³ × 1000)
  - `filament_mass_g` — filament mass in grams; **absent (not null) when
    `filament_density` is not set in the profile or the override**
  - `gcode_sha256` — SHA-256 of the produced G-code (non-deterministic; PrusaSlicer
    embeds a build timestamp)
  - `not_checked` — explicit list of unverified aspects

- `parsePrusaTime` — exported pure function; parses PrusaSlicer time strings
  (`"12m 45s"`, `"1h 2m 30s"`, `"45s"`, `"2h"`) to integer seconds.

- Stateless HTTP MCP server on port 3022 (`transport: "stateless"`, protocol
  `2026-07-28`).

- Test fixtures generated by the real engine:
  - `tests/fixtures/cube_20mm.stl` — exact 20 mm cube, 12 triangles (generated by
    `scripts/gen_cube_20mm_stl.ts`).
  - `tests/fixtures/pla_0.4_0.2.ini` — PLA test profile (non-production; 0.4 mm nozzle,
    0.2 mm layer, PLA 1.24 g/cm³, 20% infill).
  - `tests/fixtures/cube_20mm_pla.gcode` — truncated G-code produced by the real
    PrusaSlicer 2.9.2 on 2026-08-05; header + stat block (stat lines are the ground
    truth for unit tests). Generated by `scripts/gen_cube_20mm_gcode_fixture.ts`.

- The suite covers `parsePrusaTime`, G-code fixture parsing against committed real
  stats, schema invariants, MCP wire behavior, input validation, and native integration.
  Native checks are gated behind `PRUSASLICER_RUN_NATIVE=1`.

### Reference measurements (PrusaSlicer 2.9.2, aarch64 Debian trixie)

**20 mm cube + `pla_0.4_0.2.ini` (PLA 1.24 g/cm³, 0.4 mm nozzle, 0.2 mm layer, 20%
infill):**

- `filament used [mm]` = 1487.15 → `filament_length_mm` = 1487.15
- `filament used [cm3]` = 3.58 → `filament_volume_mm3` = 3580
- `filament used [g]` = 4.44 → `filament_mass_g` = 4.44
- `estimated printing time (normal mode)` = 19m 50s → `print_time_s` = 1190
- `estimated printing time (silent mode)` = 20m 40s

**10 mm cube + same profile:**

- `filament used [mm]` = 426.64
- `filament used [cm3]` = 1.03 → `filament_volume_mm3` = 1030
- `filament used [g]` = 1.27
- `estimated printing time (normal mode)` = 12m 45s → `print_time_s` = 765
- `estimated printing time (silent mode)` = 12m 50s
